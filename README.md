# Misdar App - Inspection & Report Management System

An interactive, responsive web application designed to streamline housing and duty inspection logs, track deficiencies in real time, manage administrative settings, and automate report generation.

---

## 💡 About The Project

This application solves a real-world operational challenge by replacing manual paper-based inspection procedures with an efficient, mobile-responsive web platform. It allows users to quickly file inspection reports, manage resolution statuses, configure system settings through a dedicated admin view, and instantly compile formatted PDF summary reports.

---

## Key Features

* **Real-time Deficiency Tracking:** Easily log, review, and update inspection statuses using Firebase Firestore.
* **Admin & Settings Panel:** Dedicated management view (`SettingsPage`) for configuring system preferences and administrative controls.
* **Automated PDF Export:** Custom report generator component that compiles dynamic inspection logs into downloadable, formatted PDF files.
* **State Management:** Clean global state handling powered by React's Context API.
* **Role & Security Management:** Secure data access and custom security rules built with Firebase.
* **Fully Responsive UI:** Optimized interface for seamless use across desktop and mobile devices.

---

## Tech Stack

* **Frontend:** React, JavaScript (ES6+), HTML5, CSS3 / Tailwind CSS
* **State Management:** Context API
* **Backend & Database:** Firebase Firestore, Firebase Authentication
* **Report Generation:** PDF Compilation Library
* **Deployment & Tools:** Git, GitHub, Vercel
